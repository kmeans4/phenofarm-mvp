## Code facts and research behind the revision

- `lib/auth.ts`: 30-day JWT session maximum, password-hash authentication, session-version revocation.
- `lib/account-security.ts`: verification 60 minutes; reset/change-email 30 minutes; single-use tokens; old-token cleanup is activity-driven.
- `lib/auth-rate-limit.ts`: keyed identifiers and activity-driven expiry cleanup.
- `lib/blob-storage.ts`: public Vercel Blob files; catalog removal is not remote object deletion.
- `lib/buyer-products.ts` and buyer lab-download route: small report metadata and authenticated downloads; underlying public storage remains public.
- `lib/subscription-checkout.ts`, `lib/stripe.ts`, and `.codex/payment-model.md`: recurring software subscriptions only; no wholesale fund movement.
- Browser storage inventory includes cart recovery, drafts, search history, favorites, recent activity, and view defaults. No advertising/analytics SDK was found in the app layout or package manifest. Recheck provider-side additions before publication.
- Registration shows Terms/Privacy links. It does not currently persist a dedicated policy-version acceptance event. Do not represent a versioned acceptance audit as implemented. Review that separately before relying on proof of acceptance for paid contracts.
- [FTC: Protecting Personal Information](https://www.ftc.gov/business-guidance/resources/protecting-personal-information-guide-business): use accurate disclosures, limit unnecessary collection/retention, and document retention practices. The rewrite avoids unsupported deletion deadlines and blanket claims that no financial information is stored.
- [Vermont Act 145 of 2026](https://legislature.vermont.gov/Documents/2026/Docs/ACTS/ACT145/ACT145%20As%20Enacted.pdf), sections 2415a and 4: the new act takes effect January 1, 2028, and its consumer definition excludes individuals acting solely in specified business/employment contexts. Do not describe it as already effective or assume that all website activity is exempt.
- [Vermont Security Breach Notice Act](https://legislature.vermont.gov/statutes/fullchapter/09/062), section 2435: incident handling requires separate analysis of notice obligations. The public policy does not substitute a generic security promise for an incident-response process.
